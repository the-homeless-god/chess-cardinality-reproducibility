# Chess experiment code and data

Python implementation, frozen input snapshots and machine-readable experiment records.

- `data/`: selected positions, source provenance and licenses.
- `results_*/`: saved trials, labels, game traces and numerical summaries.
- `run_*.py`, `benchmark_*.py`, `analyze_*.py`: computation and numerical analysis.
- `verify_reproduction.py`, `verify_search_integration.py`: offline verification.
