# Дополнительный протокол сравнения двух трактовок хода соперника

**Зафиксирован до зондирования апрельского корпуса Syzygy, 4 октября 2026 г.**
Это отдельная внешняя проверка авторской идеи А→Б→В. Мартовские
позиции уже просмотрены и не участвуют в подтверждающей статистике.
Два варианта отличаются только распознаванием последнего хода соперника;
множество кандидатов, критерии выбора и тестовые позиции совпадают.
«Намерение» по одной партии установить невозможно; второй вариант
является проверяемой моделью вероятной цели, а не чтением намерений.

для отбора не читаются.

## Общие критерии выбора собственного хода

В каждой позиции s и для каждого легального хода m:

1. Если m сразу ставит мат, выбрать первый такой ход по UCI.
2. Если после m соперник может поставить мат в один ход, убрать m,
   если остается хотя бы один безопасный ход.
3. А: оценить снижение числа легальных ответов соперника относительно
   условной мобильности соперника до m. Условная мобильность меняет
   сторону хода и очищает en passant; она не является реальным ходом.
4. Б: для каждого ответа соперника r посчитать число своих легальных
   ходов в s-m-r; взять минимум по r. Рост относительно текущего числа
   своих ходов — выполнение Б.
5. В: для каждого r сравнить число ответов соперника в s-m и число
   своих ходов в s-m-r; взять наихудшую абсолютную разницу. Уменьшение
   относительно текущей разницы сторон — выполнение В.

Каждый критерий возвращает пару (выполнен: 0/1, величина улучшения).
Политика сравнивает эти пары лексикографически в заданном порядке,
затем сырые А, Б и В и UCI для разрешения ничьей. Если все ходы
позволяют мат соперника, фильтр 2 их не удаляет. Для терминального
нематового хода Б принимается равным нулю.

## Варианты распознавания сценария соперника

Пусть p — позиция до последнего фактического хода соперника u,
а s — после него.

**O: наблюдаемый эффект.** Измерить относительное сокращение
числа легальных ходов текущего игрока и относительный рост
условного числа собственных ходов соперника после u.
Если оба эффекта положительны, выбрать больший; при равенстве —
нейтральный класс. Если положителен только один, выбрать А или Б.
Если оба неположительны — нейтральный класс.

**I: цель, выводимая из альтернатив.** Для каждого легального
хода v соперника из p вычислить два значения: минус число
легальных ответов текущего игрока после v (цель А) и условную
мобильность соперника после v (цель Б). Для фактического u
посчитать процентиль его ранга среди этих альтернатив по каждой
цели, с усреднением рангов при равенстве. Если процентиль А выше
процентиля Б, классифицировать А; если ниже — Б; если равны —
нейтрально. WDL и будущие ходы не используются.

При классе А порядок собственной политики **Б→В→А**, при Б —
**А→Б→В**, при нейтральном классе — **А→Б→В**. Таким образом
классификаторы могут влиять только на порядок, а не на определение
признаков. Дополнительная абляция использует всегда А→Б→В без
классификации.

## Оценка

По каждому из 250 корней Syzygy даст категорию всех легальных ходов.
Главный показатель — доля выбора максимальной WDL-категории
с точки зрения игрока; отдельно сообщается доля на позициях, где
ходы различаются по WDL, и средний regret. Cursed-win и
blessed-loss приравниваются к ничьей только в главной шкале.
Если API вернёт категории syzygy-win, maybe-win, maybe-loss,
syzygy-loss или unknown, соответствующая позиция исключается
из первичного бинарно-троичного WDL-сравнения и её число
сообщается отдельно; перекодировка после просмотра результатов
не допускается.
Парные разности O−I, O−нейтральная политика, I−нейтральная
политика и обоих вариантов минус min κ оцениваются bootstrap
по позициям (10 000 ресемплов, seed 20261004). Вывод о пользе
не делается по одной общей доле без сопоставления с baselines
и числом различающих позиций. Дополнительно сообщаются частоты
классов А/Б/нейтрально и согласие O с I.

Ограничение: даже апрельская выборка проверяет выбор одного хода,
а не победу в полной партии. Второй классификатор приближает
прошлую цель по рангу хода и не может установить психологическое
намерение игрока.
